# BioEthanol Distillation Plant Website

This project is a responsive informational website developed to present the design of a continuous distillation unit for a high-capacity corn-based bioethanol production plant.

The website summarizes the main process stages, equipment specifications, engineering design results, production capacity, and cost-related information in a clear and visually organized format.

## Project Overview

The distillation system is designed to separate the ethanol-water mixture obtained after fermentation and produce ethanol at approximately **95.6% purity**.

### Main Design Values

- Daily ethanol production capacity: **100,000 L/day**
- Annual production target: **33,000,000 L/year**
- Feed ethanol concentration: **10 wt%**
- Distillate ethanol concentration: **95.6 wt%**
- Bottom product ethanol concentration: **2 wt%**
- Column diameter: **1.264 m**
- Column height: **9.0 m**
- Theoretical tray count: **7**
- Actual tray count: **10**
- Reflux ratio: **1.6**
- Operating pressure: **1 atm**

## Website Sections

The website includes the following sections:

- Project overview
- Bioethanol production process
- Process flow diagram
- Main equipment
- Distillation column design results
- Interactive production calculator
- Cost analysis

## Main Equipment

The website introduces the main components of the distillation system:

- Distillation column
- Shell-and-tube condenser
- Kettle reboiler
- Feed tank
- Product storage tank
- Pumps
- PLC automation system

## Technologies Used

- HTML5
- CSS3
- JavaScript

No backend or database is required. The website can run directly in a browser.

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open the `index.html` file in a web browser.

Alternatively, the website can be published using GitHub Pages.


## Notes

All images and assets should remain inside the `assets` folder.  
Do not move or rename these files unless the paths inside `index.html` are updated.
